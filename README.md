🎯 Bingo Game
A simple and interactive Bingo Game built using HTML, CSS, and JavaScript. The game provides an engaging interface with both Random Mode and Manual Mode, allowing players to choose how they want to play.

✨ Features
🎲 Random Mode – Automatically generates numbers for gameplay.
✍️ Manual Mode – Allows players to manually interact with the game.
🎯 Interactive Bingo gameplay.
🔢 Dynamic number generation and selection.
🖥️ Simple and user-friendly interface.
📱 Responsive design for different screen sizes.
⚡ Lightweight and fast-loading web application.
🚪 Exit option to leave the game.
🛠️ Technologies Used
HTML5 – Structure and layout of the application.
CSS3 – Styling, responsive design, and visual presentation.
JavaScript – Game logic, interactions, and dynamic functionality.

🎮 How to Play
Open the Live Demo.

Select the desired game mode:

Random Mode
Manual Mode
Follow the on-screen instructions to play.

Continue selecting/generating numbers during the game.

Use the Exit option when you want to leave the game.
